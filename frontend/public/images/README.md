# Images de référence (galerie d'objets)

Dépose ici une image par mot, même convention de nom que pour l'audio :

- "dog"        → dog.jpg (ou .png)
- "hot dog"    → hot-dog.jpg
- "cell phone" → cell-phone.jpg

Si un mot n'a pas d'image ici, l'application affiche le badge coloré à la
place — donc là aussi, tu peux compléter progressivement.
