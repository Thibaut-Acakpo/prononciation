# Fichiers audio de référence (prononciation native)

Dépose ici un fichier audio par mot, nommé exactement comme le mot mais en
minuscules avec des tirets à la place des espaces :

- "dog"        → dog.mp3
- "hot dog"    → hot-dog.mp3
- "cell phone" → cell-phone.mp3
- "wine glass" → wine-glass.mp3

Formats acceptés : .mp3 ou .wav (les deux fonctionnent, mp3 = fichiers plus légers).

Si un mot n'a pas de fichier ici, l'application bascule automatiquement sur
la synthèse vocale du navigateur — donc pas besoin d'avoir les 80 dès le
départ, tu peux compléter au fur et à mesure.
